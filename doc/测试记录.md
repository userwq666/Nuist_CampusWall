# Nuist CampusWall 测试记录（V4.0）

## 1. 后端测试
### 1.1 测试方式
1. 工具：IntelliJ HTTP Client。
2. 用例目录：`src/test/http`。
3. 环境：本地 Spring Boot + MySQL。

### 1.2 用例覆盖
1. `account.http`：14
2. `file.http`：7
3. `post.http`：17
4. `comment.http`：13
5. `like.http`：8
6. `admin.http`：36
7. 总计：95

### 1.3 断言标准
1. 成功：`HTTP 200 + code=0`。
2. 失败：`HTTP 4xx/5xx + code!=0`。
3. 文案：优先使用返回 `message`。

### 1.4 关键失败场景
1. 未登录访问受保护接口（401 + 406）。
2. 普通用户访问管理接口（403 + 412）。
3. 目标资源不存在（404 + 409/410/414）。
4. 重复操作冲突（409 + 411/417）。
5. 参数非法（422 + 422）。
6. 上传超限（413 + 416）。

## 2. 前端联调验证
### 2.1 构建验证
1. `npm run build` 通过（Vite + Rolldown），vendor chunk 975KB（315KB gzip）。

### 2.2 页面联调清单（全部通过）
1. 注册页：表单校验 + 接口调用 + 成功跳转。
2. 登录页：接口调用 + token 存储 + 角色分流（USER->/post, ADMIN->/admin）。
3. 帖子列表：瀑布流 + 推荐/公告/我的三标签 + 搜索（URL query 驱动）+ 无限滚动 + 发布弹窗。
4. 帖子详情：正文展示 + 评论楼中楼 + 点赞/取消 + 编辑/删除（仅自己的）。
5. 个人信息：昵称/邮箱/密码修改 + 头像上传 + store 同步。
6. 管理后台：adminPing 权限校验 + 用户/帖子/评论分页 + 启用/禁用 + 详情弹窗。
7. 路由守卫：未登录拦截（->/login）、非管理员拦截（->/post）、已登录不可进登录页。

### 2.3 错误处理验证
1. 后端未启动：Axios 5s 超时 + "后端服务未启动" 提示。
2. 401：弹 token 过期提示，自动跳转登录。
3. 403/412：无权限操作提示。
4. 422：字段校验错误提示。

### 2.4 性能验证
1. 首次加载阻塞根因排查：Google Fonts（CSS link）被墙导致渲染挂起。
2. 修复：移除 `index.html` 中 `fonts.googleapis.com` 外链。
3. 路由懒加载：每页独立 chunk，首屏只加载当前页。

## 3. 结论
1. 后端 95 个 HTTP 用例全链路可稳定复现成功与失败场景。
2. 前端全部页面功能闭环，联调验证通过。
3. 项目可交付、可演示、可答辩。
