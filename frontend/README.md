# Nuist CampusWall Frontend

前端技术栈：`Vue 3 + Vite + Axios + Pinia + Vue Router + Element Plus`。

## 1. 启动方式
```powershell
cd D:\javacode\javaweb\Nuist_CampusWall\frontend
npm install
npm run dev
```

构建命令：
```powershell
npm run build
```

## 2. 当前页面
1. `/login` 登录页
2. `/register` 注册页
3. `/post` 帖子列表页
4. `/post/:id` 帖子详情页
5. `/admin` 管理页
