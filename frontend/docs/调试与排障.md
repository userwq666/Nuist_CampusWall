# 调试与排障手册（V2.0）

最后更新：2026-05-21

## 1. 常用启动命令
1. 前端：
```powershell
cd D:\javacode\javaweb\Nuist_CampusWall\frontend
npm run dev
```
2. 前端构建：
```powershell
npm run build
```
3. 后端（根目录）：
```powershell
mvn spring-boot:run
```

## 2. 常见问题与处理

### Q1 登录提示"请求失败，请稍后重试"
1. 打开浏览器 F12 -> Network，看请求是否发出。
2. 若状态为 `CORS` 或 `blocked`：检查 Vite 代理配置。
3. 若状态为 `401/403/500`：看后端日志中的错误详情。
4. 若 `ECONNREFUSED`：后端未启动，启动后端即可。

### Q2 登录成功后访问其它接口还是 401
1. 检查 localStorage 是否有 `token`。
2. 检查请求头是否带 `Authorization: Bearer ...`。
3. 检查 token 是否过期（后端默认 7200 秒，2 小时）。
4. 前端 Axios 响应拦截器已处理 401 -> 自动跳转登录页。

### Q3 管理员登录后跳后台失败
1. 检查 `userInfo.role` 是否为 `ADMIN`。
2. 检查路由守卫 `requiresAdmin` 判断是否取到 `isAdmin`。
3. 管理后台打开时会先调 `adminPingApi`，失败则跳回首页并提示。

### Q4 上传接口返回错误
1. 确认请求是 `multipart/form-data`。
2. 字段名必须是 `file`。
3. `fileType` 仅支持 `POST/COMMENT/AVATAR`。
4. 图片大小超过 5MB 会返回 413。
5. 图片上传成功但回显 404：检查后端 `WebMvcConfig` 静态资源映射。

### Q5 帖子/评论提交失败但看不出原因
1. 看后端返回的 `message` 文本。
2. 看响应中的 `code` 与 HTTP 状态码。
3. 常见是参数名写错（`fileID` vs `fileId`）。

### Q6 页面白屏或首次加载极慢
1. **检查 index.html 是否有被墙的外部资源**（如 Google Fonts）。
2. F12 -> Network 看是否有挂起（pending）的 CSS/JS 请求。
3. 移除 `fonts.googleapis.com` 等外链即可恢复。

### Q7 图片不显示（回显 404/ERR_CONNECTION_REFUSED）
1. 确认后端启动了（提供 `/static/upload` 代理）。
2. 确认 `app.file.local-root` 目录存在。
3. 确认 Vite 代理 `/static/upload` -> `localhost:8080`。
4. 确认后端 `WebMvcConfig` 中 `addResourceHandlers` 配置正确。

### Q8 构建失败
1. 检查 `npm run build` 输出中的具体错误。
2. 动态 `import()` 写法确认路径正确。
3. 组件未注册：检查是否在 `main.js` 中 `app.component()`。
4. ElementPlus 按需引入但未配置插件：改回全局引入。

## 3. 自测清单（答辩前）
1. `npm run build` 必须通过。
2. 登录、注册至少各测 1 次。
3. token 清空后访问受保护页会被拦截。
4. 管理员和普通用户各测一次跳转逻辑。
5. 图片上传 + 回显验证一次。
6. 管理员启停用户/帖子/评论各验证一次。
7. 不启动后端，看前端是否能给出"后端未启动"提示。
8. 手机宽度（360px）下布局不崩。
