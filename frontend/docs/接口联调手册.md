# 接口联调手册（V2.0）

最后更新：2026-05-21

## 1. 全局约定
1. 前端请求基址：`/api`（通过 Vite 代理到 `http://localhost:8080`）
2. 后端统一返回：`{ code, message, data }`
3. `code = 0` 代表业务成功
4. 受保护接口需带：`Authorization: Bearer <token>`

## 2. 账户模块
### 2.1 登录
1. 接口：`POST /api/account/login`
2. 请求体：
```json
{
  "username": "admin",
  "password": "123456"
}
```
3. 关键返回字段：
```json
{
  "code": 0,
  "data": {
    "token": "...",
    "userInfo": {
      "id": 1,
      "role": "ADMIN",
      "username": "admin"
    }
  }
}
```
4. 前端落地（已实现）：
   1. 登录成功后调用 `authStore.setLogin(token, userInfo)`。
   2. 角色分流：`ADMIN -> /admin`，其他角色 -> `/post`。

### 2.2 注册
1. 接口：`POST /api/account/register`
2. 请求体：
```json
{
  "username": "tom",
  "password": "123456",
  "nickname": "tom",
  "educationEmail": "tom@nuist.edu.cn"
}
```
3. 前端本地校验（已实现）：
   1. 非空校验：用户名/密码/确认密码/昵称/教育邮箱。
   2. 用户名规则：长度 3-20，仅字母数字。
   3. 密码规则：长度 >= 6，确认密码一致。
   4. 邮箱规则：域名需包含 `.edu`（支持 `.edu`、`.edu.cn`、`.edu.xxx`）。
4. 成功处理：`ElMessage` 提示成功并跳转 `/login`。

### 2.3 我的信息
1. `GET /api/account/my` — 获取当前用户信息
2. `POST /api/account/my/update` — 更新信息，请求体 `{ nickname?, educationEmail?, password?, fileId? }`

### 2.4 前端封装的 API
所有接口统一在 `src/api/account.js` 中封装：
- `loginApi(data)` -> `POST /api/account/login`
- `registerApi(data)` -> `POST /api/account/register`
- `myInfoApi()` -> `GET /api/account/my`
- `updateMyInfoApi(data)` -> `POST /api/account/my/update`

## 3. 帖子模块
### 3.1 接口列表
1. `GET /api/post/page?pageNum=1&pageSize=5` — 公开分页
2. `GET /api/post/notice/page?pageNum=1&pageSize=5` — 公告分页
3. `GET /api/post/my/page?pageNum=1&pageSize=5` — 我的帖子
4. `GET /api/post/{id}` — 帖子详情
5. `POST /api/post/create` — 创建，请求体 `{ title, content, fileID }`
6. `POST /api/post/update/{id}` — 更新，请求体 `{ title, content, fileId }`
7. `POST /api/post/delete/{id}` — 删除

### 3.2 字段注意
1. `create` 用 `fileID`（大写 ID）
2. `update` 用 `fileId`（小写 d）

### 3.3 前端封装的 API（src/api/post.js）
- `postPageApi(params)`
- `postNoticePageApi(params)`
- `postMyPageApi(params)`
- `postDetailApi(id)`
- `postCreateApi(data)`
- `postUpdateApi(id, data)`
- `postDeleteApi(id)`

## 4. 评论模块
### 4.1 接口列表
1. `GET /api/comment/page?postId=xx&pageNum=1&pageSize=5` — 评论分页
2. `GET /api/comment/my/page?pageNum=1&pageSize=5` — 我的评论
3. `POST /api/comment/create` — 创建，请求体 `{ postId, content, replyToCommentId?, replyToUserId?, fileId? }`
4. `POST /api/comment/delete/{id}` — 删除

### 4.2 字段注意
1. `create` 用 `fileId`（小写 d）

### 4.3 前端封装的 API（src/api/comment.js）
- `commentPageApi(params)`
- `commentCreateApi(data)`
- `commentDeleteApi(id)`

## 5. 文件上传
1. 接口：`POST /api/file/upload?fileType=POST|COMMENT|AVATAR`
2. 请求类型：`multipart/form-data`
3. 表单字段名：`file`
4. 返回 `data` 为文件 ID（`Long`）
5. 大图限制 5MB

## 6. 点赞模块
1. `POST /api/like/do` — 点赞
2. `POST /api/like/undo` — 取消点赞

请求体：
```json
{
  "targetType": "POST",
  "targetId": 1
}
```

`targetType`：`"POST" | "COMMENT"`

## 7. 管理端接口
1. 鉴权探针：`GET /api/admin/ping`
2. 用户治理：`GET /api/admin/user/page`、`POST /api/admin/user/enable/{userId}`、`POST /api/admin/user/disable/{userId}`
3. 帖子治理：`GET /api/admin/post/page`、`GET /api/admin/post/detail/{postId}`、`POST enable/disable`
4. 评论治理：同上

### 前端封装的 API（src/api/admin.js）

- `adminUserPageApi(params)` / `adminUserEnableApi(id)` / `adminUserDisableApi(id)`
- `adminPostPageApi(params)` / `adminPostDetailApi(id)` / `adminPostEnableApi(id)` / `adminPostDisableApi(id)`
