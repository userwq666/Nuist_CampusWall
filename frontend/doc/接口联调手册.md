# 接口联调手册（V1.0）

最后更新：2026-04-15

## 1. 全局约定
1. 前端请求基址：`/api`（通过 Vite 代理到 `http://localhost:8080`）
2. 后端统一返回：`{ code, message, data }`
3. `code = 0` 代表业务成功
4. 受保护接口需带：`Authorization: Bearer <token>`

## 2. 账户模块
### 2.1 登录
1. 接口：`POST /api/account/login`
2. 请求体：
```json
{
  "username": "admin",
  "password": "123456"
}
```
3. 关键返回字段：
```json
{
  "code": 0,
  "data": {
    "token": "...",
    "userInfo": {
      "id": 1,
      "role": "ADMIN",
      "username": "admin"
    }
  }
}
```

### 2.2 注册
1. 接口：`POST /api/account/register`
2. 请求体：
```json
{
  "username": "tom",
  "password": "123456",
  "nickname": "tom",
  "educationEmail": "tom@nuist.edu.cn"
}
```

### 2.3 我的信息
1. `GET /api/account/my`
2. `POST /api/account/my/update`

## 3. 帖子模块
1. `GET /api/post/page?pageNum=1&pageSize=5`
2. `GET /api/post/{id}`
3. `POST /api/post/create`
4. `POST /api/post/update/{id}`
5. `POST /api/post/delete/{id}`

### 字段注意
1. `create` 用 `fileID`（大写 ID）
2. `update` 用 `fileId`（小写 d）

## 4. 评论模块
1. `GET /api/comment/page?postId=xx&pageNum=1&pageSize=5`
2. `POST /api/comment/create`
3. `POST /api/comment/delete/{id}`

### 字段注意
1. `create` 用 `fileId`（小写 d）

## 5. 文件上传
1. 接口：`POST /api/file/upload?fileType=POST|COMMENT|AVATAR`
2. 请求类型：`multipart/form-data`
3. 表单字段名：`file`
4. 返回 `data` 为文件 ID（`Long`）

## 6. 点赞模块
1. `POST /api/like/do`
2. `POST /api/like/undo`

请求体：
```json
{
  "targetType": "POST",
  "targetId": 1
}
```

## 7. 管理端接口
1. 鉴权探针：`GET /api/admin/ping`
2. 用户治理：`/api/admin/user/page`、`enable/{userId}`、`disable/{userId}`
3. 帖子治理：`/api/admin/post/page`、`detail/{postId}`、`enable/{postId}`、`disable/{postId}`
4. 评论治理：`/api/admin/comment/page`、`detail/{commentId}`、`enable/{commentId}`、`disable/{commentId}`

## 8. 前端联调顺序（必须按顺序）
1. 登录（先拿 token）
2. 注册（验证异常提示）
3. 帖子分页（能展示）
4. 帖子详情 + 评论列表
5. 发表评论 / 删除评论
6. 个人信息修改
7. 管理后台分页与启停
