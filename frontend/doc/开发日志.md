## 2026-05-21｜全量联调闭环 + 性能优化 + 文档同步
### 本轮目标
1. 完成前端所有页面与后端接口的对接。
2. 修复性能问题和 Bug。
3. 全量文档同步。

### 本轮完成
1. **页面联调**：
   - 帖子列表：瀑布流 + 推荐/公告/我的三标签 + 搜索 + 无限滚动 + 发布弹窗。
   - 帖子详情：评论楼中楼 + 点赞/取消 + 编辑/删除（仅自己的帖子）。
   - 个人信息：头像上传 + 昵称/邮箱/密码修改 + store 同步。
   - 管理后台：adminPing 权限校验 + 用户/帖子/评论三表分页 + 启停 + 详情弹窗。
2. **Bug 修复**：
   - `pageSize.value` 误用（`const` 当作 `ref`）。
   - `alert` -> `ElMessage`。
   - 管理台列名 `id` -> `userId`/`postId`/`commentId`。
   - index.html title 乱码修复。
3. **性能优化**：
   - 移除 Google Fonts 外链（国内被墙，消除首次渲染 2 分钟阻塞）。
   - 路由懒加载（每页独立 chunk）。
   - 移除全局 ~300 个图标注册。
   - Axios 超时 10s -> 5s + ECONNREFUSED 提示。
4. **API 层**：新增 `updateMyInfoApi`；动态 `import()` 全部改为静态 import。
5. **文档同步**：doc/ + frontend/doc/ + README 共 19 份文档全量同步至 V4.0。

### 本轮关键决策
1. ElementPlus 全局注册：dev 模式单 chunk 优于 `unplugin-element-plus` 拆成 54 请求。
2. 不移除 `unplugin-element-plus` 依赖，保留在 package.json 中但 vite.config.js 未启用。

### 验证
1. `npm run build` 构建通过。
2. 首次加载从 ~2 分钟降至 ~3s（受 ElementPlus 首屏解析影响，浏览器可缓存）。
