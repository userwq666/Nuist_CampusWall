# 页面与路由说明（V1.0）

最后更新：2026-04-15

## 1. 页面范围（本作业）
1. 登录页
2. 注册页
3. 帖子主页（瀑布流）
4. 帖子详情页（含评论）
5. 个人信息修改页
6. 管理员后台页

## 2. 当前已存在路由
文件：`frontend/src/router/index.js`

1. `/login` -> `LoginView.vue`
2. `/register` -> `RegisterView.vue`
3. `/post` -> `PostListView.vue`
4. `/post/:id` -> `PostDetailView.vue`
5. `/admin` -> `AdminView.vue`

默认重定向：`/` -> `/post`

## 3. 建议新增路由
1. `/profile` -> `ProfileView.vue`（个人信息修改）
2. `/:pathMatch(.*)*` -> `NotFoundView.vue`（404 页面）

## 4. 访问权限设计
1. `public`：`/login`、`/register`
2. `auth`：`/post`、`/post/:id`、`/profile`
3. `admin`：`/admin`

## 5. 路由守卫规则（建议）
1. 未登录访问 `auth/admin` 页面：跳转 `/login`
2. 已登录访问 `/login`、`/register`：跳转 `/post`
3. 非管理员访问 `/admin`：跳转 `/post` 并提示无权限

## 6. 最小页面验收标准
1. 登录成功后：普通用户进入 `/post`，管理员进入 `/admin`
2. 帖子卡片点击可进入 `/post/:id`
3. 刷新后不会丢失登录态
4. 未登录直接输入 `/admin` 地址会被拦截
