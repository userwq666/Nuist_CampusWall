# 页面与路由说明（V2.0）

最后更新：2026-05-21

## 1. 页面范围（本作业）
1. 登录页
2. 注册页
3. 帖子主页（瀑布流）
4. 帖子详情页（含评论）
5. 个人信息修改页
6. 管理员后台页

## 2. 当前路由表
文件：`frontend/src/router/index.js`

| 路径 | 组件 | 守卫 | 说明 |
|------|------|------|------|
| `/login` | `LoginView.vue` | guestOnly | 已登录不可访问 |
| `/register` | `RegisterView.vue` | guestOnly | 已登录不可访问 |
| `/post` | `PostListView.vue` | 开放 | 游客可浏览 |
| `/post/:id` | `PostDetailView.vue` | requiresAuth | 需登录 |
| `/profile` | `ProfileEditView.vue` | requiresAuth | 需登录 |
| `/admin` | `AdminView.vue` | requiresAuth + requiresAdmin | 管理员专属 |

默认重定向：`/` -> `/post`

## 3. 权限矩阵
1. `public`：`/post`、`/login`、`/register`
2. `requiresAuth`：`/post/:id`、`/profile`
3. `requiresAuth + requiresAdmin`：`/admin`

## 4. 路由守卫规则（已实现）
1. 已登录访问 `guestOnly` 页面（`/login`、`/register`）会跳转 `/post`。
2. 未登录访问 `requiresAuth` 页面会跳转 `/login`。
3. 非管理员访问 `requiresAdmin` 页面会跳转 `/post`。

## 5. 验收结果（V2.0）
1. 登录成功后角色分流：`ADMIN -> /admin`，`USER -> /post`。
2. 刷新后登录态保留：`token/userInfo` 从 localStorage 恢复。
3. 未登录直接访问 `/admin` / `/profile` 拦截到 `/login`。
4. `/post` 对游客开放（产品策略，吸引注册）。
5. 全部路由使用 `lazy import`，每页独立 chunk。
