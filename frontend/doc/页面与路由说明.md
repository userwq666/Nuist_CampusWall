# 页面与路由说明（V1.1）

最后更新：2026-04-15

## 1. 页面范围（本作业）
1. 登录页
2. 注册页
3. 帖子主页（瀑布流）
4. 帖子详情页（含评论）
5. 个人信息修改页
6. 管理员后台页

## 2. 当前已存在路由
文件：`frontend/src/router/index.js`

1. `/login` -> `LoginView.vue`
2. `/register` -> `RegisterView.vue`
3. `/post` -> `PostListView.vue`
4. `/post/:id` -> `PostDetailView.vue`
5. `/admin` -> `AdminView.vue`

默认重定向：`/` -> `/post`

## 3. 建议新增路由
1. `/profile` -> `ProfileView.vue`（个人信息修改）
2. `/:pathMatch(.*)*` -> `NotFoundView.vue`（404 页面）

## 4. 当前权限矩阵（按现有代码）
1. `public`：`/post`、`/login`、`/register`
2. `requiresAuth`：`/post/:id`
3. `requiresAuth + requiresAdmin`：`/admin`

## 5. 路由守卫规则（已实现）
1. 已登录访问 `guestOnly` 页面（`/login`、`/register`）会跳转 `/post`。
2. 未登录访问 `requiresAuth` 页面会跳转 `/login`。
3. 非管理员访问 `requiresAdmin` 页面会跳转 `/post`。

## 6. 本轮验收结果（2026-04-15）
1. 登录成功后角色分流已实现：`ADMIN -> /admin`，`USER -> /post`。
2. 刷新后登录态保留：`token/userInfo` 从 localStorage 恢复。
3. 未登录直接访问 `/admin` 可被拦截到 `/login`。
4. `/post` 对游客开放，用于吸引注册（产品策略）。

## 7. 下一轮路由调整建议
1. 新增 `/profile`（个人信息页），权限建议 `requiresAuth`。
2. 补 `404` 路由：`/:pathMatch(.*)*`。
3. 给路由增加 `name` 字段，避免硬编码字符串跳转。
