# 前端开发计划（V2.0）

最后更新：2026-05-21

## 1. 总体目标
在后端可交付基础上，完成可演示的前端闭环

## 2. 当前基线（V2.0 — 全已完成 ✅）
1. ✅ 登录页已接入登录接口，角色分流已实现。
2. ✅ 注册页已接入注册接口并完成前端校验。
3. ✅ 路由守卫已建立（guestOnly / requiresAuth / requiresAdmin）。
4. ✅ 帖子列表：瀑布流 + 推荐/公告/我的三标签 + 搜索 + 无限滚动 + 发布弹窗。
5. ✅ 帖子详情：正文 + 评论楼中楼 + 点赞 + 编辑/删除。
6. ✅ 个人信息：昵称/邮箱/密码/头像修改。
7. ✅ 管理后台：user/post/comment 三表分页 + 详情 + 启停。
8. ✅ 错误处理：401/403/422/500 + ECONNREFUSED 友好提示。
9. ✅ 性能优化：路由懒加载 + 移除 Google Fonts + Axios 超时 5s。
10. ✅ 样式收口：小红书风格 + 移动端适配。
