# 样式与组件规范（V1.0）

最后更新：2026-04-15

## 1. 样式阶段策略
1. 先功能后样式：功能跑通后再统一视觉。
2. 样式分两轮：
   1. 结构轮：布局、间距、可读性、响应式
   2. 视觉轮：色彩、阴影、交互反馈

## 2. 基础页面规范
1. 表单页（登录/注册）宽度建议 `360px ~ 460px`。
2. 主内容区左右留白统一，避免贴边。
3. 按钮主次明确：主操作使用 `type="primary"`。
4. 错误提示统一使用组件消息（后续建议 `ElMessage`）。

## 3. 帖子瀑布流规范
1. 推荐方案：CSS `column-count` 快速实现。
2. 卡片避免固定高度，依内容自然撑开。
3. 图片使用 `width: 100%`，避免变形。
4. 列间距与卡片间距统一（如 16px）。

## 4. 组件拆分建议
1. `PostCard.vue`：帖子卡片。
2. `CommentList.vue`：评论列表。
3. `CommentInput.vue`：评论输入框。
4. `AppHeader.vue`：导航与用户入口。

## 5. 命名规范
1. 组件名：`PascalCase`，如 `PostCard.vue`。
2. API 函数：`xxxApi`，如 `loginApi`。
3. store action：动词开头，如 `setLogin`、`clearToken`。
4. CSS 类名：语义化，不用无意义缩写。

## 6. 移动端适配底线
1. 360px 宽度可用，不出现横向滚动。
2. 表单输入框和按钮在手机上可点击。
3. 文本不重叠、不截断关键操作按钮。
