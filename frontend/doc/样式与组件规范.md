# 样式与组件规范（V2.0）

最后更新：2026-05-21

## 1. 样式策略
1. **NUIST 主题**：采用南京信息工程大学官方蓝色系。
2. 主色调：`#004098`（NUIST 蓝），搭配 `#1A5CAD` 渐变。
3. 卡片圆角 12px + 阴影。
4. 移动端适配：360px 宽度不崩布局。

## 2. 页面样式规格
1. 登录/注册页：居中卡片式，左半 NUIST 蓝色渐变背景 + 校名标识。
2. 帖子列表：CSS `column-count` 瀑布流（PC 4 列，平板 2 列，手机 1 列）。
3. 帖子详情：全宽卡片 + 评论树缩进。
4. 管理后台：Element Plus `el-table` 分页表格。
5. 导航栏：固定顶部，紫金色 NUIST 标识 + 搜索 + 用户下拉菜单。

## 3. 组件清单（实际代码）
1. `NavBar.vue` — 顶部导航 + 搜索栏 + 用户下拉菜单
2. `LoginView.vue` — 登录页
3. `RegisterView.vue` — 注册页
4. `PostListView.vue` — 帖子列表（瀑布流 + 标签 + 搜索 + 无限滚动 + 发布弹窗）
5. `PostDetailView.vue` — 帖子详情（含评论楼中楼 + 点赞 + 编辑/删除）
6. `ProfileEditView.vue` — 个人信息修改（头像上传 + 昵称/邮箱/密码）
7. `AdminView.vue` — 管理后台（user/post/comment 三表）

## 4. 命名规范
1. 组件名：`PascalCase`，如 `PostCard.vue`。
2. API 函数：`xxxApi`，如 `loginApi`。
3. store action：动词开头，如 `setLogin`、`clearToken`。
4. CSS 类名：语义化，不用无意义缩写。

## 5. 响应式断点
1. `>= 1024px`：PC 4 列瀑布流。
2. `768px ~ 1023px`：平板 2 列。
3. `< 768px`：手机 1 列 + 底部导航。
