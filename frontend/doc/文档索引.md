# Nuist CampusWall 前端文档索引（V1.0）

最后更新：2026-04-15

## 1. 核心文档
1. `frontend/doc/页面与路由说明.md`：页面范围、路由设计、访问权限。
2. `frontend/doc/接口联调手册.md`：前端调用口径、入参、返回、易错字段。
3. `frontend/doc/开发计划.md`：按阶段推进任务与每日目标。
4. `frontend/doc/样式与组件规范.md`：页面样式、组件拆分、命名规范。
5. `frontend/doc/调试与排障.md`：联调问题与排查路径。

## 2. 当前实现状态（对应代码）
1. 已有路由：`/login`、`/register`、`/post`、`/post/:id`、`/admin`。
2. 已有认证状态：`token + userInfo` 存储于 Pinia + localStorage。
3. 已有请求封装：Axios 统一拦截器，三段式返回适配。
4. 已有登录接口文件：`src/api/account.js`。
5. 当前页面多为占位，正在联调完善。

## 3. 阅读顺序建议
1. 先看 `页面与路由说明.md`（先明确做什么）。
2. 再看 `接口联调手册.md`（明确如何调接口）。
3. 然后按 `开发计划.md` 执行。
4. 编码时参考 `样式与组件规范.md`。
5. 遇到报错直接查 `调试与排障.md`。
